## Como publicar

A PWA precisa estar em um endereço HTTPS.

### Hostinger
1. Abra o Gerenciador de Arquivos do domínio/subdomínio.
2. Crie uma pasta, por exemplo: `/public_html/drop/`
3. Envie TODOS os arquivos desta pasta para lá.
4. Abra no navegador:
   `https://SEU-DOMINIO/drop/`

### GitHub Pages
1. Crie um repositório.
2. Envie estes arquivos para a raiz.
3. Ative Settings > Pages.
4. Publique pela branch principal.

## Instalar no Android
1. Abra a URL no Chrome.
2. Toque em ⋮
3. Escolha “Instalar app” ou “Adicionar à tela inicial”.
4. Confirme.

## Instalar no iPhone
1. Abra a URL no Safari.
2. Toque em Compartilhar.
3. Escolha “Adicionar à Tela de Início”.

## Observação importante
